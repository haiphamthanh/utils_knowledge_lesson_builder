# Tài liệu dự án

Thư mục này là nơi duy nhất lưu tài liệu đang có hiệu lực của Knowledge Lesson
Builder. Các file trong `specs/` là lịch sử brainstorming và prototype tham
chiếu, không phải hướng dẫn vận hành hiện tại.

| Tài liệu | Nội dung |
|---|---|
| [`architecture.md`](architecture.md) | Kiến trúc, sequence diagram và đánh giá hệ thống |
| [`knowledge-model.md`](knowledge-model.md) | Ranh giới lesson, graph và learning path |
| [`authoring.md`](authoring.md) | Quy trình phân loại, viết và xuất bản lesson |
| [`resources.md`](resources.md) | Lifecycle `raw → pool → done` |
| [`agent-instructions.md`](agent-instructions.md) | Quy tắc bắt buộc dành cho agent |
